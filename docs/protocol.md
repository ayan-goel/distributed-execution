# Worker wire contract

## Shared schema (D04a)

`proto/dispatch/worker/v1/worker.proto` is the single source for Go and Rust.
Go bindings in `gen/` are checked in; Rust bindings are generated by the Cargo
build from the same file. Package version is `dispatch.worker.v1`; registration
negotiates integer protocol version 1. Removed field numbers must be reserved.

The service covers registration, heartbeat/inventory, acquisition/reconciliation,
phase changes, batched renewal, scoped uploads, log segment registration, and
completion. File bytes use object storage; gRPC carries metadata and bounded JSON.
The server and client implementations must apply the 4-MiB message limit plus
per-field/count validation; declarations alone do not enforce these bounds.

## Authority and replay

An authority tuple contains job, attempt, generation, worker, and session. UUIDs
use strings; counters, durations, and byte sizes use integer wire types. These
values must never pass through floating-point JSON representations. Zero enum values
mean unspecified, not authorization or success. Exit status uses presence-aware
`optional int32`, so an omitted status is distinguishable from exit zero.

| Operation | Required replay behavior in the service implementation |
| --- | --- |
| Register | Same request/incarnation returns its existing session; stale sessions remain fenced |
| Heartbeat | Inventory is reconciled; repeating a request cannot create authority |
| Acquire | Same session/request returns the stored assignment or no-work outcome |
| List assignments | Recompute remaining authority, never replay a fresh lease |
| Report phase | Event identity deduplicates; phase cannot move backward |
| Renew | Validate each item independently and return its decision/remaining duration |
| Create/finalize upload | Request/upload identity deduplicates grants and verified versions |
| Register logs | Deduplicate stream/range and artifact identity |
| Complete | Same completion ID/digest returns the accepted outcome; changed payload conflicts |

Workers interpret lease durations conservatively from request-send time with a
safety margin. A late response does not restart the lease. `STOP_REQUESTED` is
separate from `FENCED`; neither authorizes further workload execution.

Remote authentication binds these claimed worker IDs to provisioned mTLS identities.
Transfer URLs are sensitive bearer capabilities and must not be logged. Object
versions/checksums identify uploaded bytes, but only a valid completion transaction
can make a manifest canonical. These are implementation requirements for later slices.

## Generation and verification

Pinned tools: protoc 34.1, protoc-gen-go 1.36.11, protoc-gen-go-grpc 1.6.2,
Tonic 0.14.6 and Prost 0.14.3, plus exact transitive dependencies in lockfiles.

```sh
make generate
make generate-check
make protocol-test
```

The round-trip fixture writes a Go assignment, decodes/re-encodes it in Rust,
and compares all fields in Go. It exercises a generation above 2^53, resource sizes
above 2^32, Unicode arguments, authority identity, lease duration, and JSON bytes.
This is wire compatibility evidence, not a real worker execution or mTLS test.

`make generate-check` compares checked-in Go output with freshly generated files.
Rust regeneration is part of every build when the schema changes. CI installs the
official Linux protoc archive by fixed version with a recorded SHA-256 check.
The acquisition assignment variant is boxed in Rust to avoid inflating every
no-work/error response. Cargo build products live under `.local/cargo-target` to
keep Go package discovery independent of Rust's incremental build directories.
